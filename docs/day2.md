# Day 2 - SOLID Principles

## What I Learned

Today I learned about SOLID principles:

- Single Responsibility Principle
- Open/Closed Principle
- Liskov Substitution Principle
- Interface Segregation Principle
- Dependency Inversion Principle

## Why SOLID improves maintainability

SOLID principles help in writing clean and structured code.
Each class has a single responsibility, so it is easy to understand and modify.
It reduces bugs and improves code readability.

## Example in real systems

SOLID principles are used in:

- E-commerce applications
- Banking systems
- Hospital management systems

## My Understanding

Initially, I wrote a bad design where one class handled everything.
Then I refactored the code into multiple classes.
This made the code cleaner and easier to manage.
